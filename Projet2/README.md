# Dilemme du prisonnier itéré (HAI716I, projet 2, partie 1)

Tournoi de stratégies en Python. La graine aléatoire est fixée à 42, donc les résultats sont reproductibles.

## Lancer les tournois

Tournoi de base (étapes 1 et 2) :
python classic_tournament.py

Tournoi modifié (étape 3 : bruit et horizon inconnu) :
python modified_tournament.py

## Contenu

- `classic_tournament.py` : tournoi de base
- `modified_tournament.py` : tournoi avec les modifications de l'étape 3
- `duelist.py` : classe joueur
- `strategys/` : les stratégies
- `tournament_report.py` : affichage des rencontres
- journal de bord : `journal_de_bord.pdf`
